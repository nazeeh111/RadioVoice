# Verification and compatibility

The original GNU Radio 3.10.10.0 flowgraphs retain their DSP topology, coefficients,
rates and device defaults. Python and GRC path configuration now use the same
GPL-3.0 helper. The three enabled writers get unique per-run directories; the
Saleae input is explicit. `laser_zmod` retains its disabled WAV source block and
has no enabled writer. Do not interpret it as a recording workflow.

## Recompute checks

```
python3 -m pip install -r requirements-test.txt
python3 -m unittest discover -s tests -v
python3 offline_am.py --output result-997
python3 offline_am.py --tone 1733 --output result-1733
```

The numerical test compares the production NumPy FIR against independent SciPy
`lfilter` on random complex samples. A known analytic sine independently checks
AM recovery, sample rate and amplitude on two different inputs. Local NumPy 2.3.5
runs produced amplitude 0.99845/0.99919 for 997/1733 Hz and residual RMS below
1.3e-8. Startup samples are excluded explicitly, and fitted phase is reported.
Timing in each manifest is an observation, not a before/after speedup claim.

GNU Radio tests skip explicitly when its dependency is absent. The public CI
installs distribution GNU Radio and runs real vector-source/filter/envelope/sink
blocks without SDR, microphones, speakers or Qt windows. It also compiles the
retained GRC source and uploads generated Python and recomputed outputs. CI
results apply to the tested commit; a local NumPy pass alone proves neither GRC
execution nor device behavior. Qt/hardware legacy applications are not launched.

## Signal and license boundaries

The fixture signal is newly computed from an analytic sine with original code;
no external capture, private communication, optical target or trained model is
used. The AM reference is a separate bounded headless workflow, not a claim that
all legacy experiments work or that their hardware defaults fit a device.
All new DSP/path/test code is GPL-3.0 alongside the retained source. First-party
documentation remains MIT. No RF transmission or external signal collection occurs.


The four shipped Python files were regenerated by hosted GNU Radio Companion
3.10.9.2 from the updated GRC. An AST comparison against original7105bd67
confirms all connected DSP/filter/gain operations selected in the comparison are
unchanged (19/19/30/23 core calls respectively; actual counts in task evidence).
CI compares generated and shipped Python syntax trees and checks actual path
constructor arguments. GRC compilation requires `gr-osmosdr` block definitions
in addition to GNU Radio; it does not open a device. The offline GNU backend
succeeded on997/1733Hz with amplitudes0.99845/0.99920 and residual RMS below2.2e-7.
